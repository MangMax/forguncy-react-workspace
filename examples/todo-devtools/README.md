# TodoList 的 Forguncy DevTools

从仓库根安装依赖后运行：

```sh
cd examples/todo-devtools
vp dev
```

打开终端打印的地址。首次打开 Vite DevTools 时，用终端打印的一次性验证码授权，再从 Dock 打开 **Forguncy**。面板由 Vite DevTools 的 JSON Render 组件渲染。

1. 打开 **接管单元格**，按坐标选择当前页的 Cell。展开各项能力查看同步配置与本地模拟。设计器连接状态显示在面板顶部。
2. 打开 **页面级**，查看离线样例中的页面属性、事件与命令。
3. 在 **模拟与日志** 切换 **有数据**、**空列表** 或 **保存失败**。切换会重置 Cell 状态和调用记录。收起面板勾选待办，再打开面板查看事件参数和命令返回码。

`App.tsx` 通过现有运行时接口调用数据源、事件和命令。`fixture.ts` 提供模拟结果，`devtools.ts` 负责场景切换和显示最近的调用。场景和记录在本地开发服务器内存中，同一服务器的浏览器标签页共用。

在本目录运行 `pnpm build` 生成单元格产物，`pnpm plan` 查看离线同步计划。实际保存、设计器事件命令和页面联动需要在真实活字格页面验证。

### 读取已打开的设计器工程

在 PowerShell 中指定已存在的页面后启动预览，例如 `$env:FGC_INSPECTOR_PAGE = 'Lobe待办'`，再运行 `vp dev`。从 **Forguncy → 设计器 → 读取设计器** 读取本机 11234 端口上的当前工程。此试验只读页面设置与 React AI 单元格配置，结果与本地模拟分开展示。

面板按能力展示真实配置。数据源包含输出列和绑定源，属性包含绑定公式和示例值，事件包含参数签名和附带的设计器命令。页面加载命令单独列出，可展开查看详细设置。上传限制缺少的字段标为「未返回」。
